3. ÉCHELLE NUMÉRIQUE « 1/XXXX » SUR LES CADRES DES CARTES DES FICHES
----------------------------------------------------
Où : fonction mapHTML() + wrapper mapHTMLFramed() + ajout d'un badge .scaleBadge.
Méthode exacte du calcul de l'échelle :
  * On utilise la résolution native Web Mercator (EPSG:3857) au centre de la
    carte :  res (m/px) = 156543.0339 × cos(latitude) / 2^zoom.
  * On ramène en m/px CSS en supposant un écran 96 DPI
    (1 CSS px = 25,4/96 mm = 0,00026458 m).
  * Le dénominateur affiché N = round(res / 0.00026458), garantissant
    N ≥ 1 et une valeur lisible (1/2 500, 1/5 000, 1/10 000, 1/25 000, etc.).
  * Calcul encapsulé dans _scaleDenom(z,lat) puis _scaleText(z,lat).
Implémentation :
  * Nouvelle fonction mapHTMLFramed(a,all,W,H,i,n,col,ec,overview=false) qui
    appelle mapHTML(...) et enveloppe le SVG retourné dans
    `<div class="mapframe">${svg}${badge?`<div class="scaleBadge">…</div>`:''}</div>`.
  * fiche(k) utilise désormais mapHTMLFramed() au lieu de mapHTML() directement.
  * Le zoom réel PZ (variable globale du moteur de rendu) est utilisé comme
    entrée : la mise à jour est automatique à chaque moveend/zoomend.

Comment tester : ouvrir une fiche d'intervention → chaque carte (vue d'ensemble
+ cartes détaillées) affiche un bandeau blanc en bas à droite avec
« Échelle 1/XXXX ». Zoomer : la valeur change.
